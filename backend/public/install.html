Download

Open this page on your TV browser and select Download. If your TV has no browser, download on another device and copy the APK using a USB drive or file-transfer app.

02

Install

Open the downloaded APK. If Android asks, allow “Install unknown apps” for the browser or file manager you used, then return and install Vert TV.

03

Make yourself at home

Open Apps → Vert TV and sign in. Add it to your home-screen favourites using your TV launcher’s options.

Replacing an older test build?

If Android refuses the update, uninstall the older Vert TV test APK first, then install this one. Your account, paid activation and saved library remain on the server. Sign in again after installation.

My TV says “App not installed”

Check that it runs Android 8.0 or newer and has free storage. Keep Android System WebView updated through your TV’s app store or system updates. Open the APK from the file manager, and remove an older conflicting test copy if necessary. A managed TV may require its administrator’s permission. This APK is for Android TV, Google TV and compatible Android devices; it cannot install on Samsung Tizen or LG webOS.

Built-in filtering is available in the Android app. The web app uses the ad protection supplied by your browser. Blocking cannot guarantee removal of every ad or a player’s waiting period.

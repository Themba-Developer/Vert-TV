# Welcome background artwork

Generated with the built-in image generation tool, then copied without editing to:

- `backend/public/assets/cinema-wall.png`
- `app/src/main/res/drawable-nodpi/cinema_wall.png`

The fictional artwork is illustrative, not a statement of titles available in the library. Website CSS and native Canvas/ValueAnimator add the motion and readability overlays. Web motion can be paused and honors reduced-motion preferences; native motion honors disabled system animators and pauses when hidden.

Final generation prompt:

> Use case: ads-marketing. Asset type: production background artwork for an Android TV streaming welcome screen and website. Create a wide landscape 16:9 cinematic collage of many fictional movie and television posters arranged in a tight, slightly tilted wall grid, 6 columns and 3 rows extending beyond edges. Photoreal film-poster artwork: space exploration astronaut and blue planet, African crime thriller city at night, sweeping golden desert adventure, intimate romantic drama with two adults, stormy ocean voyage, wildlife documentary lion, neon futuristic metropolis, mountain expedition, historical epic, moody detective portrait. Original fictional imagery, no existing movie franchises, no streaming service logos, no text or lettering whatsoever. Rich premium cinematic lighting and teal, amber, burgundy and midnight blue colors. Each poster feels like a distinct polished key art photograph, with thin black gutters. Edge-to-edge continuous collage, no user interface, no buttons. Keep it vivid enough to show through a separate dark overlay supplied by the app. Save output image and return its local file path.
